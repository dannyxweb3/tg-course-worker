P 站每日排行榜图(缩略)+ **原图 zip 包直传**(2.48GB/样本),少量网盘(nekocloud/pikpak)链接。缩略图 + 原图 zip 直传 Telegram(免费 CDN),**扒取 pixiv 每日 Top50 榜**。日更约 14 条,晚 15–18 点为主。

## 二、成本(含运营时间)
抓取 pixiv + 打包 + 发布 bot + VPS ¥30–200/月;图片/zip Telegram 直传;**全自动抓取打包,运营时间近乎为零**。经常性现金 **¥30–250/月**。

## 四、增长(涨粉)策略
**P 站排行榜刚需搬运 + 互推换量。** ACG 用户追榜刚需;#互推 + @Hu_Tuibot 与 ACG 号互推。9 万订阅但 ERR 2.5% 偏低——互推堆量为主,真实活跃一般;原图 zip 直传是留存点。
