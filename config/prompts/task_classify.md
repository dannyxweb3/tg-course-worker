给下面这份素材做两件事：**路由到某个内容方向** + **判定处理档位**。

## 可选的内容方向
{VERTICALS}

对每个方向单独打 0-10 分（这份素材有多适合发到那个方向），然后选分最高的一个。
所有方向都低于 5 分，说明这份素材哪都不合适。

## 档位定义
- `P0` 原样：内容本身质量和结构都已经很好，只需要清掉推广尾巴、@提及、邀请链接等噪音
- `P1` 排版：内容有价值但结构松散，需要加标题、分段、代码块、要点整理
- `P2` 重写：信息有价值但表达差、太啰嗦、或需要提炼成教程形态
- `P3` 丢弃：哪个方向都不沾边，或纯广告 / 纯资讯无教程价值

## 输出
严格输出 JSON，不要任何额外文字。`scores` 的 key 必须用上面给出的 slug：
{
  "scores": {"slug-a": 8, "slug-b": 2},
  "vertical": "得分最高的 slug，都不合适则填空字符串",
  "relevance": 0-10 的整数，等于所选方向的得分,
  "topic_tags": ["最多4个中文或英文标签"],
  "suggested_level": "P0" | "P1" | "P2" | "P3",
  "reason": "一句话说明判断依据，30字以内"
}
